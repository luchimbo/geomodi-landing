# Logos de IAs

Coloca aquí los logos de las inteligencias artificiales mencionadas en la sección "La búsqueda por IA es el nuevo Google".

**Logos necesarios:**
- ChatGPT
- Grok
- Gemini
- Claude

**Recomendaciones:**
- Formato: PNG con transparencia o SVG
- Tamaño: 100-200px de ancho
- Mismo estilo/formato para todos

**Nombres sugeridos:** `chatgpt-logo.png`, `grok-logo.png`, etc.
