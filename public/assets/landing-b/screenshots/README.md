# Screenshots de Funcionalidades

Coloca aquí las capturas de pantalla para la sección de Funcionalidades (ProductShowcase).

**Screenshots necesarios:**
1. **Análisis avanzado** - Captura mostrando el análisis de productos
2. **Optimización de publicaciones** - Captura del proceso de optimización
3. **Integraciones nativas** - Captura de la integración con Tienda Nube/WooCommerce

**Recomendaciones:**
- Formato: PNG o WebP
- Tamaño: 1200x800px (formato landscape)
- Optimizadas para web
- Consistencia visual entre las 3 imágenes

**Nombres sugeridos:**
- `analisis-avanzado.png`
- `optimizacion-publicaciones.png`
- `integraciones-nativas.png`
