# Assets de Redes Sociales

Coloca aquí assets relacionados con redes sociales y SEO.

**Opcional:**
- Favicon personalizado
- Open Graph image (para compartir en redes sociales)
- Twitter Card image

**Recomendaciones:**
- **Favicon:** 32x32px o 512x512px (PNG o ICO)
- **OG Image:** 1200x630px (PNG o JPG)
- **Twitter Card:** 1200x675px (PNG o JPG)

**Nota:** Los iconos de Instagram y Twitter en el footer ya están incluidos como componentes de lucide-react.
